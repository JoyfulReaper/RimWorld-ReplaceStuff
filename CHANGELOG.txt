6/19/2026: Version 0.0.30
Replace Stuff: Performance Edition

This release is a large fork-level update from the original Replace Stuff base repo. The biggest change is that the mod is now organized around a more explicit replacement pipeline and a broader compatibility system, with the goal of keeping the original gameplay intact while reducing overhead and making future support easier.

Added:
- A new replacement pipeline centered around `ReplacementPipeline`, `ReplacementValidator`, and `ReplacementUtility`.
- Registry-based compatibility support so replacement handlers can be discovered through attributes and XML-backed definitions.
- A legacy compatibility bridge for older replacement data and handler behavior.
- Dedicated compatibility handlers for third-party features such as QualityBuilder and interchangeable item groups.
- New state transfer and storage preservation logic for replacement events, including persistent building data and storage contents.
- Expanded support for wall attachments, worktables, turrets, and storage-specific replacement behavior.
- Better support for over-mineable, over-wall, and bridge-adjacent construction cases.
- Updated mod metadata, preview assets, and project organization for the Performance Edition fork.

Changed:
- Reworked the core replacement flow to use clearer stages for validation, extraction, destruction, spawning, and state restoration.
- Split feature code into smaller namespaces and patch groups, making the mod easier to maintain and debug.
- Refactored the old hardcoded replacement and compatibility logic into reusable registries, handlers, and patch helpers.
- Improved storage handling, including preservation of labels, settings, priorities, filters, and contents where applicable.
- Updated over-wall cooler and vent handling to better fit RimWorld 1.6 and current mod compatibility patterns.
- Refined blueprint, frame, and spawn behavior for replacement, over-mineable, and bridge placement paths.
- Modernized the project setup, including solution and metadata updates.
- Updated translations and keyed text across supported languages.

Fixed:
- Several null-safety and map-reference issues during spawn and replacement flow.
- Cases where replacement state could be lost between destruction and rebuild.
- Problems around duplicate replacement work, validation overlap, and construction ordering.
- Issues with blueprint, frame, and ghost behavior in special placement situations.
- Some attachment and wall-adjacency edge cases that could interfere with replacement or reconstruction.
- Various internal cleanup issues that previously made the code harder to extend or reason about.

Compatibility Notes:
- The mod is still under active development and should be treated as an alpha/early beta quality fork.
- Some compatibility behavior has been moved into the new handler/registry system, so mod integrations should now be easier to add or adjust.
- Support is centered on RimWorld 1.6 in this fork.

Known Issues:
- Some edge cases may still exist around complex storage replacements and modded building interactions.
- Because this is a substantial refactor, unusual mod combinations may still expose regressions.
- Please test carefully before relying on it in long-running saves.

Developer Notes:
- This fork is focused on performance, maintainability, and compatibility rather than preserving the original file layout.
- The source tree now separates feature areas such as `Replace`, `NewThing`, `OverMineable`, `PlaceBridges`, `DestroyedRestore`, and `Compatibility`.
- The original base repo has been heavily reorganized, so this changelog reflects the fork as a new implementation path rather than a small patch set.
